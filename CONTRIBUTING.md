# Contributing

Questions, "would it work with my unit", and reports from other setups are all welcome: open an issue.

**Pull requests:** one change per PR, and say what you tested it on and for how long. It switches real
equipment, so the safety guards (SOC floor, stale-data cut-off, load cap, watchdog) are not loosened without
a very good reason. Run `npm test` before you push.

By submitting a pull request you agree your contribution is licensed under this repo's licence
(`LICENSE.md`, PolyForm Noncommercial 1.0.0) and that the maintainer may also relicense it as part of the
project. Your name stays in the git history.
